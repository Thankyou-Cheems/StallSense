# Repository Guidelines

## Project Structure & Module Organization
- `src/index.ts` contains the TypeScript CLI wrapper, argument parsing, report loading, and summary output.
- `scripts/collect-windows-health.ps1` contains the read-only Windows collection logic shared with the packaged skill.
- `dist/` is the compiled JavaScript output generated by `tsc` (not committed by default).
- `README.md` documents the troubleshooting guide and expected behavior.
- Root configs: `package.json` (scripts/bin) and `tsconfig.json` (TS compiler settings).

## Build, Test, and Development Commands
- `npm run build` — compile TypeScript from `src/` into `dist/`.
- `npm run start` — run the CLI from `dist/index.js` (build first).
- `npm run audit` — run the full read-only health audit (`dist/index.js audit`).
- `npm run analyze` — compatibility alias for `audit`.
- `npm run fix` — run the fix flow with `--pcie-off` (build first).

Example:
```bash
npm run build
npm run audit -- --days 14 --json
```

## Coding Style & Naming Conventions
- TypeScript (ES2020) with `strict: true` from `tsconfig.json`.
- Indentation: 2 spaces; use semicolons and double quotes to match existing files.
- Naming: `camelCase` for functions/variables, `PascalCase` for types/interfaces.
- No formatter or linter is configured; keep changes consistent with `src/index.ts`.

## Testing Guidelines
- No automated test suite is present.
- If you add tests, prefer a `tests/` folder and document the runner in `package.json`.

## Commit & Pull Request Guidelines
- Commit messages follow Conventional Commits with scopes, e.g. `feat(cli): ...` or `docs(readme): ...`.
- Keep commits focused and include a short, imperative summary.
- PRs should include: brief description, how to validate (commands/output), and screenshots/log snippets if CLI output changes.

## Security & Configuration Tips
- The CLI is Windows-only and executes PowerShell and `powercfg` commands.
- Fix commands may require an elevated shell depending on system policy; note this in PRs if behavior changes.
